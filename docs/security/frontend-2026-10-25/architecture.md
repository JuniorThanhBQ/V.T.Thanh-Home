# Why — trust boundaries
API/model Markdown reaches marked then DOMPurify allowlist then Angular innerHTML string binding. API blog image/slug fields reach URL bindings and encoded detail paths. Admin identity is server-session-backed, UI signals start unauthenticated, credentialed admin writes bootstrap CSRF; backend authorization and cookies are unreviewed. Visitor registration sends browser language/time zone; contact/chat send dummy-boundary-relevant user inputs and Turnstile tokens. Chat skips new challenges after the first successful message. Preferences use language/theme allowlists and fixed-origin metadata. Edge viewer handler uses operator environment credentials for fixed-host analytics requests and returns numeric count/null. Vercel config declares proxy destinations, private API caches, CSP and framing protections; deployed behavior is unobserved.
